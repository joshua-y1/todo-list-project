# Todo List App

A todo list app built with Express, EJS, and MongoDB. Add, complete, and delete todos — data persists in MongoDB.

## Tech Stack
Node.js, Express, EJS, MongoDB, dotenv

## Setup
1. Clone the repo and run `npm install`
2. Create a `.env` file with:
DB_STRING=your_mongodb_connection_string
3. Run `node server.js`
4. Visit `localhost:3000`
